Dos funciones nuevas para diferenciar el proyecto

La plataforma ahora soporta viajes con punto de conexión y una dinámica de estacionamiento colaborativo basada en ocupación real del vehículo.

Viaje con punto de conexión

Abordaje en cualquier hub autorizado

El conductor puede publicar un trayecto con modalidad de conexión. Así, el pasajero identifica un punto común de encuentro como Parque Puebla, Solesta o Explanada y se integra a la ruta desde ese lugar.

  • Filtro por hub de abordaje.
  • Modo de viaje directo o con conexión.
  • Mayor cobertura sin duplicar rutas.
Rodando Parking

Pase para estacionamiento colaborativo

Si una ruta fue marcada para Rodando Parking y reúne al menos dos lugares reservados, el conductor puede generar un código de pase desde su panel. Esto permite presentar evidencia de viaje compartido.

  • Validación por reservaciones confirmadas.
  • Código único generado desde el backend.
  • Estadísticas para la administración.

Rodando Parking

Estacionamiento colaborativo con evidencia digital

El programa premia viajes que realmente transportan a más estudiantes. El pase se genera desde el panel del conductor cuando existen al menos dos lugares reservados en una ruta marcada para parking.

Condiciones para generar el pase

  1. Publicar una ruta con la opción Rodando Parking activada.
  2. Recibir al menos dos reservaciones confirmadas.
  3. Generar el código desde el panel personal.

Panel administrativo

El administrador puede revisar cuántas rutas usan conexión, cuántas participan en Rodando Parking y el total de usuarios y reservaciones activas.

La cuenta de administrador se crea automáticamente al iniciar el proyecto.
